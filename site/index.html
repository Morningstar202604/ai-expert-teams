WHAT'S INSIDE

不只是角色清单，是完整机制

内置工作流与门禁

每队按 Phase 分阶段推进，产出过自检清单、质检角色与通用质检门禁，H 级问题不交付。

跨团队协作编排

总调度按场景路由；小红书图文 = 内容+视觉、论文+代码 = 学术+开发，多团队并行、牵头整合、交接模板齐全。

准确性与多检验

断言分级、证据强度判定、反例搜索、交叉验证、独立事实核查单兵——任何人不得自证自查。

纯 Markdown 资产

无运行时依赖、不绑定任何框架。读文件即用，可导出 system prompt 文本或 JSON，接入任意 agent。

GET STARTED

三种方式，接入任意 Agent

01

直接读团队 Markdown

适合支持「读文件 + 派子 agent」的框架：把团队目录交给它，专家即可被路由调用。

teams/content-writing-team/
团队自包含：TEAM.md 编排 + agents/ 专家 + skills/ 技能
02

一键导出 system prompt

运行导出脚本，得到每名专家的纯文本提示词与全队汇总包，直接粘贴进任何 agent。

python3 export-agents.py
输出 dist/agents.json + 101 份单专家文本 + 7 份整队汇总
03

整目录复制

把 teams/ 目录整体复制给支持目录式专家的框架，配置即完成，无需转换。

cp -r teams/ /your/agent/path
无运行时依赖，复制即用
