# 深度研究（多轮检索 + 综合报告）

本 skill 适配**学术论文、全栈选型、数学建模**等需要系统性调研的场景。它区别于单次 web-search：先把大问题拆成可检索的子问题，多轮迭代检索，再把分散证据综合成一份可溯源的报告。

## 这是什么
一套受控的调研方法论。强调证据分级、来源可溯、不确定性显式声明。最终产物是一份结构完整的报告，而不是一堆链接的堆砌。

## 何时使用
- 「系统调研一下 X 方向的现状/方案/争议」。
- 技术选型：对比多个框架/数据库/云服务，要带依据。
- 文献综述：某课题的方法演进、争议点、空白。
- 写报告/开题前的证据收集阶段。

## 核心步骤
1. **拆研究问题**：把大问题拆成 3–6 个可独立检索的子问题，明确每个子问题要回答什么。
2. **首轮广撒**：对每个子问题做 1–2 轮检索，快速摸清版图与关键来源。
3. **追读关键源**：对高价值来源（官方文档、综述论文、权威对比）打开原文精读，不只看摘要。
4. **补缺口与反方**：主动找反对意见、失败案例、已知局限，不只收集支持性证据。
5. **证据分级**：给每条结论标证据强度（官方/一手 > 权威二手 > 社区经验 > 传闻）。
6. **综合成文**：按子问题组织，结论先行，每个结论后挂引用；最后给「共识 / 争议 / 未知」三段。

## 报告结构模板
```
# <主题> 调研报告
## 1. 研究问题与范围（本次回答什么、不回答什么）
## 2. 分主题结论（每个子问题一节，结论先行 + 证据 + 引用）
## 3. 共识点（多来源一致）
## 4. 争议与分歧（来源之间冲突，列出各方依据）
## 5. 证据不足 / 未知（查不到、不确定性高的部分，显式声明）
## 6. 参考来源（编号、标题、URL、抓取时间）
```

## 证据与引用清单
- [ ] 每个事实性结论都有编号引用，无裸断言。
- [ ] 引用标注了来源类型（官方文档/论文/博客/社区）与抓取时间。
- [ ] 冲突观点并列呈现，不选择性引用。
- [ ] 数字/版本/价格类结论核对过原文，不是二手转述。
- [ ] 「未知/证据弱」单独成节，不强行给确定答案。
- [ ] 报告区分「事实」与「我的推断」。

## 易错点
- **搜索即综述**：把前几条搜索结果拼接成报告，没有精读、没有交叉验证。
- **确认偏误**：只搜支持预设结论的来源，不找反方证据。
- **引用不可溯**：结论挂了个链接，但链接打开是另一篇文章而非该结论出处。
- **过度确定**：证据很弱却写得斩钉截铁；应显式标注不确定性。
- **范围蔓延**：调研越写越宽，最后偏离原始问题。每节回扣研究问题。
- **忽略时效性**：技术领域引用多年前的对比结论，没有标注「可能已过时」。
